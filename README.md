# BinarySearchTreeProjesi
# Proje 3  

[7, 5, 1, 8, 3, 6, 0, 9, 4, 2]   
dizisinin Binary-Search-Tree aşamalarını yazınız.


Root : 7  
5, 7'den küçük olduğu için soluna,  
1, 5'ten küçük olduğu için 5'in soluna,  
8, 7'den büyük olduğu için sağına,  
3, 1'den büyük olduğu için 1'in sağına,  
6, 5'ten büyük olduğu için 5'in sağına,  
0, 1'den küçük olduğu için 1'in soluna,  
9, 8'den büyük olduğu için 8'in sağına,  
4, 3'ten büyük olduğu için 3'ün sağına,  
2, 3'ten küçük olduğu için 3'ün soluna eklenir.  

Ağaç şu yapıya sahip olur:

```
       7
     /  \
    5     8
   /  \     \
  1    6     9
 /  \
 0   3
    / \
    2  4

```
